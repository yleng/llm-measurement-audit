# Reproducing the randomized-experiment illustration

All records are synthetic. No participant answers, external datasets, human ratings, or model calls are used. The policy-notice story motivates the illustration; it is not a report of an experiment conducted with people.

Run `python3 docs/scripts/render_experiment_example.py` from the repository root in a documentation environment with matplotlib installed. Runtime analysis needs only Python's standard library. The script generates the CSV, frozen design JSON, CLI report snapshots, three-way summary JSON, and PNG/SVG figures. It uses independent Python `random.Random` streams for assignment (seed 401), human outcomes (402), judge noise (403), and audit selection (404). Seeds and parameters are fixed, with no retry or selection on results.

For 2,000 IID units, `A ~ Bernoulli(0.5)`, `H(0) = H(1) = 50 + Normal(0,10²)`, `S = H + 8A + Normal(0,3²)`, and `R ~ Bernoulli(0.2)` independently. Scores are unbounded illustrative points. Only selected human labels are written to the input CSV. Known full-frame human outcomes are used solely to record a diagnostic difference in the summary, never by the CLI correction.

The CLI runs in `frozen_score` mode. Both corrected and AI-only intervals come directly from the package. For the human-only documentation baseline, the script takes the difference between audited-arm human means, with `SE² = s_H1²/n_audited1 + s_H0²/n_audited0`, using a 1.96 normal multiplier (computed as a normal quantile). This baseline is appropriate here because audit inclusion is uniform and independent. It must not be reused unchanged with unequal selection probabilities.

All displayed intervals target IID population contrasts. The known population human-reference effect is zero; the realized full-frame human difference is approximately −0.443 because assignment leaves chance imbalance. The package interval is not a conditional interval for that fixed realized difference. A single draw establishes neither coverage nor superiority over another estimator. The script checks no acceptance threshold and never retries a draw.

The policy-notice example uses synthetic data throughout. Its estimates and figures are generated by the bundled reproduction script.
