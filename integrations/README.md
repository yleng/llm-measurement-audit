# Human-reference evaluation with PPI and Inspect

Combine automated scores with human ratings to estimate differences under your human rubric.

| Your setting | Use | What you receive |
|---|---|---|
| A randomized intervention produces text outcomes | [PPI tutorial](ppi_py/README.md) | A worked notebook estimating the human-reference treatment effect and its interval using `ppi_py`. |
| Two model versions answer the same prompts in Inspect | [Inspect adapter](inspect_ai/README.md) | A comparison report built from matched evaluation logs and sampled human pair ratings, with input validation. |

Both include runnable synthetic examples, result figures, and input requirements. Choose the design that matches how your data were collected.
